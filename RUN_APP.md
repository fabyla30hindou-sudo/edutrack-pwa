# Lancer EduTrack

## Prerequis
- Node.js installe
- Python 3 installe
- Dependances frontend deja installees (`npm install`)
- Dependances backend deja installees (`pip install -r backend/requirements.txt`)

## Lancement automatique (Windows)
Depuis la racine du projet:

```bat
start_app.bat
```

Cela ouvre 2 fenetres:
- Backend FastAPI: `http://127.0.0.1:8000`
- Frontend Vite: `http://localhost:5173`

## Lancement manuel
Backend:

```bat
python backend_server.py
```

Frontend:

```bat
npm run dev
```
